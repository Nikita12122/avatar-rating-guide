01

Open Roblox Studio

Start the Avatar Rating game first
   
     
           
  1. 1Open AvatarRatingStudio.rbxl in Roblox Studio.
    2.        
  2. 2Press Play to start the game in a local test session.
    3.        
  3. 3Leave the game running while you finish the next setup steps.
    4.

02

Set up and start TikTok LIVE

Go LIVE before launching the bridge app
   
     
           
  1. 1Open TikTok LIVE using the account you want to stream from.
    2.        
  2. 2Set up your stream and make sure your LIVE is actually running.
    3.        
  3. 3Keep the LIVE open while using Avatar Rating Studio.
    4.

Use the arrows, dots, or horizontal scrolling to browse screenshots.
   
 
 
   
03

Launch Avatar Rating Studio

Start the desktop app and connect TikTok
   
     
           
  1. 1Double-click Start Avatar Rating Studio.bat.
    2.        
  2. 2When prompted, enter the TikTok username hosting your LIVE, with or without the @ symbol.
    3.        
  3. 3Allow the app to prepare its components and wait for the dashboard to open. Keep the terminal window running.
    4.      
     
1 / 2
Use the arrows, dots, or horizontal scrolling to browse screenshots.
   
 
 
   
04

Create the Cloudflare Bridge

Generate a URL to connect Roblox
   
     
           
  1. 1In the dashboard, find the Cloudflare Bridge card and click Create Bridge.
    2.        
  2. 2Wait for the bridge URL to appear, then click Copy Link or copy the URL manually.
    3.        
  3. 3Keep Avatar Rating Studio running. The temporary URL may change when you create a new bridge.
    4.      
     
1 / 2
Use the arrows, dots, or horizontal scrolling to browse screenshots.
   
 
 
   
05

Connect Roblox to the Bridge

Paste the URL into the running Roblox game
   
     
           
  1. 1Return to the running Roblox Studio test and locate the Bridge URL panel.
    2.        
  2. 2Paste the URL you copied from the dashboard into the Roblox bridge field.
    3.        
  3. 3Click Connect and wait for a success message. Check the dashboard heartbeat to confirm Roblox is communicating.
    4.
